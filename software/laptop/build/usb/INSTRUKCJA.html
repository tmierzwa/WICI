WICI: przygotowanie stacji z pamięci USB

Aplikacja działa prosto z tej pamięci. Niczego nie instaluje i nie potrzebuje internetu; w Windows i macOS nie potrzebuje też uprawnień administratora, a w Linuksie dostęp do portu stacji może wymagać jednorazowo polecenia z sudo (niżej). Panel otwiera się w przeglądarce tego komputera; dane panelu nie wychodzą poza komputer.

Stacja pracuje bez laptopa. Odłączenie przewodu albo zamknięcie aplikacji niczego w stacji nie psuje.

Windows 10 i 11

Otwórz pamięć USB w Eksploratorze plików i kliknij dwukrotnie START-WINDOWS.exe. Jeśli Windows pokaże okno „System Windows ochronił ten komputer”, wybierz „Więcej informacji”, a potem „Uruchom mimo to”.

macOS 10.15 i nowszy (Intel), 11 i nowszy (Apple Silicon)

Otwórz pamięć USB w Finderze i kliknij dwukrotnie START-MAC. Jeśli macOS odmówi otwarcia programu od nieznanego dewelopera: w macOS 14 i starszym kliknij go z klawiszem Control, wybierz „Otwórz” i potwierdź; w macOS 15 i nowszym zamknij komunikat, otwórz Ustawienia systemowe → Prywatność i ochrona, na dole wybierz „Otwórz mimo to” i potwierdź hasłem.

Linux (komputer PC, x86_64)

Kliknij dwukrotnie START-LINUX.desktop. Jeśli menedżer plików tego nie pozwala, kliknij plik prawym przyciskiem i wybierz „Zezwól na uruchamianie”. Albo w terminalu, w katalogu pamięci USB: sh START-LINUX.sh.

Gdy panel pokazuje brak uprawnień do portu stacji, wpisz w terminalu sudo usermod -aG dialout $USER (w Arch Linux grupa uucp), wyloguj się i zaloguj ponownie. Bez hasła administratora tego komputera użyj innego laptopa. Gdy panel zgłasza brak biblioteki libcrypto (OpenSSL), uruchom system Linux z pamięci USB albo użyj innego laptopa.

Gdy coś nie działa

  • Panel szuka stacji bez końca: sprawdź przewód (niektóre przewody USB-C tylko ładują) i czy stacja jest włączona.
  • Port zajęty: zamknij inne programy do portów szeregowych (monitor portu, Arduino IDE, terminal).
  • Przeglądarka się nie otworzyła: adres panelu jest w oknie terminala (działa raz) albo uruchom START ponownie; drugi START otwiera ten sam panel nowym adresem.

Zawartość pamięci opisuje plik build-manifest.json: wersje, sumy SHA-256 i źródła wszystkich plików.
