Aplikacja WICI została zamknięta albo przestała odpowiadać. Uruchom START ponownie.

Podłącz stację przewodem USB

  1. Włącz stację (ogniwa albo źródło 12 V).
  2. Połącz ją z tym komputerem przewodem USB-C z zestawu.
  3. Panel sam znajdzie stację. Sterowniki nie są potrzebne.
