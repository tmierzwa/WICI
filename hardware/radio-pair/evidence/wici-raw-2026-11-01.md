# WICI-Link raw frame check on two Wio SX1262 modules

2026-11-01, two USB-connected XIAO ESP32-S3 carriers with antennas attached.
Both ran the `pair-0.4` diagnostic image extended with `TXHEX`/`RXHEX`. The
host generated authenticated WICI-Link v1 frames with the Python encoder and
compared every received radio byte with the transmitted frame.

| Direction | Frame | Bytes | Result |
|---|---|---:|---|
| A → B | DATA | 44 | exact |
| B → A | HACK | 19 | exact |
| A → B | DATA, maximum payload | 255 | exact |
| B → A | DATA, maximum payload | 255 | exact |

Command: `hardware/radio-pair/.venv/bin/python hardware/radio-pair/tools/wici_raw_test.py /dev/cu.usbmodem1101 /dev/cu.usbmodem2101`.
The host sends long `TXHEX` commands in 48-byte USB chunks; an unpaced 517-byte
command was lost at the diagnostic board's USB receive FIFO before radio TX.

This checks raw payload integrity on the Wio pair. It does not measure the
production `Bench` scheduler, the 200 ms HACK deadline, or power-cut safety on
the RAK4631 kits and prototype required for D21.
