# Archiwum

Archiwum przechowuje treści ze wcześniejszego planu WICI: własny profil radiowy P1, dwa wykonania radia (TI CC1120 i ST S2-LP), stanowiska deweloperskie A/B, własną płytkę stacji przed pilotażem i własny blok zasilania poziomu 3. Plan wstrzymano po przeglądzie praktycznym 2026-10-08 (F99), a 2026-10-29 przeniesiono jego treści z bieżących dokumentów (F119); obowiązujący plan opisuje [rozdział 08 koncepcji](../concept/08-plan-weryfikacji-i-decyzje.html).

Pliki archiwum nie są wymaganiami. Liczby w nich pochodzą z modelu w stanie z 2026-10-29 ([`software/reference`](../../software/reference/README.md)); gdyby decyzja D10 wróciła jako otwarta, są punktem wyjścia, a nie gotową alternatywą.

| Plik | Treść |
|---|---|
| [p1-koncepcja.md](p1-koncepcja.md) | P1 i warianty sprzętu z rozdziałów 04–07 koncepcji: porównanie z LoRa, budżety czasu i łącza, energia z odbiornikiem CC1120, własny blok zasilania poziomu 3, ocena wykonania stanowisk i płytki R02 |

Kod firmware dla P1 i stanowisk (obrazy `bench-*`, sterowniki CC1120 i S2-LP) zostaje w [`firmware`](../../firmware/README.md); o jego usunięciu zdecyduje się osobno.
